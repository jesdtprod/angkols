Standardize all UI controls and elements across the application using a consistent, reusable design system that follows UI/UX best practices.

Apply consistent styles to buttons, text inputs, dropdowns, checkboxes, badges, tables, cards, dialogs, alerts, toast nitification and other components. Define shared design tokens for font families, font sizes, font weights, colors, spacing, component dimensions, border widths, corner radii, and shadows. Use these consistently, with appropriate variations for visual hierarchy and component purpose.

Ensure the interface is fully responsive and adapts naturally to mobile, tablet, and desktop screens. Adjust layouts, typography, spacing, navigation, and control sizes for each device, maintaining readable content, comfortable touch targets, and avoiding unintended horizontal scrolling.

Include clear hover, focus, active, disabled, loading, validation, and error states where applicable. Follow accessibility best practices for contrast, labels, and keyboard navigation.

Skeleton loading must accurately match each page’s actual layout and content structure, including the placement and approximate dimensions of headings, cards, table rows, images, and other content. Adapt skeletons to each responsive layout and minimize layout shifts when the content loads.
